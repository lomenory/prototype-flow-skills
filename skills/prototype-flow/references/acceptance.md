# 场景验收与证据

用于首次制作、评审或交接时选择最小充分场景。日常 Demo 调整完成必要检查、及时更新业务 PRD 并保存修订，不默认整理完整覆盖、归档截图或展示工作台；首次制作仍完成必要质量检查和框架接入。评审或交接再集中整理约定范围，不要求每次局部修改重跑全部流程。

| 场景 | 观察结果 |
| --- | --- |
| 两种来源含冲突 | 保留各自出处，关键未决项清楚，不编造已确认业务规则 |
| 业务对齐与保留成果 | 区分原文、后续决定与设计推导；保留指定组件及交互，退出旧语义；技术配置不自动变成用户操作入口 |
| 混合界面批注 | 呈现细节落在设计依据，产品行为更新 PRD，状态关系更新相应契约；已授权范围继续执行 |
| 从既有 PRD 进入 | 不重复发起全量资料整理，按范围拆分并保留稳定身份 |
| 富文本保存和需求定位 | 标题、表格、图片、链接及需求块往返后不丢失，移动标题仍能定位 |
| PRD 被外部修改 | 旧修订保存被拒绝，未保存草稿保留，可比较双方内容 |
| 两模块共享规则改变 | 标记已知受影响需求，Agent 补充隐含影响，Demo 保持业务状态一致 |
| 生成时 PRD 再次修改 | Demo 仍绑定原输入，明确过期情况，不能覆盖较新正文 |
| 截图入口 | 从看板直达相同页面状态，刷新恢复，继续跨模块流程 |
| 完整历史 | 旧 PRD、页面、图片一起可读；比较有具体差异；恢复创建新修订 |
| 飞书部分失败 | 本地仍可用，成功文档不重写，失败项读回后恢复，无重复创建 |
| 工作台只读 | PRD、画布、历史和资料可浏览；无新增、编辑、上传、版本写入入口；HTTP 写请求返回 405，项目文件不变 |
| 需求复制 | PRD 与画布详情复制准确的名称和编号；剪贴板失败明确提示且可手动复制 |
| 确认关闭待分析 | 当前及旧确认记录只关闭覆盖且未改变的需求；确认后新变更、依赖影响仍显示待分析 |
| 只读检查外部变化 | state/document/compare/validate 和 HTTP GET 前后文件字节及修改时间不变；refresh 才持久化 |
| 无依赖模块修改 | 局部 Demo 保持有效；显式共享规则或传递依赖变化仍使其过期 |
| 截图替换或入口改变 | 旧验证失效；流程步骤中的缺失引用能被保存校验和 validate 发现 |
| 连续小幅修改 Demo | 同一工作稿编号与目录持续保存修订，不每轮增加完整冻结版本；任务输入和恢复依据保留 |
| 细节调整一次收尾 | 需求或页面范围显式选择，复用编辑回执和保存模板；字段补丁与必要阶段变化一次保存，阶段未变不重写；旧完整绑定调用仍兼容 |
| 日常轻量调整 | 完成本次必要检查、变化的业务规则及时落回 PRD、保存修订；不为全绿标签额外复验，不强制完整覆盖或截图归档 |
| 入口与评审材料 | 新增、修改或删除入口时维护必要精确关联且无失效入口；未变关联不重复；评审交接才集中整理约定范围覆盖和截图，未验证保持未知 |
| 证据装配 | 从实际报告生成最小保存候选，哈希、任务、范围过期拒绝；静态、失败、未跑与继承不冒充本轮浏览器通过；装配不结束任务 |
| 待复核解释 | 区分本轮新增和延续，列出实际资源或输入原因；复验成功清除旧原因，未知依赖保持保守 |
| 调整成本与证据有效性 | 同次读取复用文件与哈希；外部修改、共享样式变化及恢复数据篡改仍失效；指标包含恢复保存并分列实际阶段，不把命令时间当 Agent 总耗时 |
| 工作台管理刷新 | 自动摘要读取不扫描无关 Demo 字节；管理刷新保持阅读位置，不含预览 token/iframe 刷新；独立 Demo 手动刷新，历史/冻结损坏仍拒绝预览 |
| 工作稿证据与恢复 | 受影响截图失效，未变化证据需有适用依据；恢复旧修订产生新修订，不覆盖原记录 |
| 评审冻结与交付下载 | 冻结产物保持当时内容和真实状态；下载使用当前已保存修订对应的冻结版 |
| 解压双击兼容 | 默认完整解压后双击 Demo 入口可显示图标并执行受影响路径；资源清单、HTTP 预览和实际人工打开分别记录，未确认不标通过；历史冻结内容保持原样 |
| 当前 Demo 损坏后恢复 | 完好历史可恢复，恢复前备份保留损坏文件及说明，历史不变 |
| 中断任务历史续作 | 固定输入及部分输出进入快照；新任务恢复这些内容，不覆盖实时任务 |
| 图片成功后正文失败 | 同一飞书计划继续剩余正文，已成功图片不重复上传，固定输入不变 |
| 按需需求图流程 | 写命令默认不启动服务、不附 requirementMap；显式 --requirement-map 准备服务并返回信息；工作台与对话快照按需展示，不作为保存收尾条件 |
| 同图自动更新 | 实际保存需求变更后待更新，实际任务开始后生成中，适用页面复验保存后已验证；仍有效的选中、展开与键盘焦点保留 |
| 覆盖分母与证据 | demoCoverage 只来自明确验收；旧数据缺分母保持未知；任务完成、单页面验证和旧截图均不能补造完整覆盖 |
| 简单查询与兼容参数 | 简单查询只读交付文字且不启动服务；旧 --no-requirement-map 兼容且与 --requirement-map 互斥；普通保存不关闭已有图，独立 Demo 验证继续用 preview |
| 独立服务生命周期 | preview 不读工作台构建、不全量 state；按项目/种类/协议复用，工作台退出后预览仍访问，旧实例不删新注册 |
| 当前 Demo 固定入口 | current 指针推进后同一入口转到新产物；准确产物路径与历史保持原样，PRD基线与修订可查，无新业务副本 |
| 运行版本与重新连接 | 安装变化显示旧版或未知，不自动终止服务；显式重启只影响匹配实例并保持端口；同源页面重新加载恢复阅读状态 |
| 需求图服务停止 | 关闭页不停止后台服务；requirement-map --stop 停止本项目需求图和工作台，preview 保留；之后普通写命令不重启服务，显式需求图请求才准备 |
| 默认入口与旧深链 | 单绑定或明确默认直接新窗口打开；多绑定无默认保留精确链接，旧 mode=demo 保留版本/对象，不自动弹窗 |
| 冻结与历史定位 | artifact/binding 共同定位，冻结使用自己的 frozenRelations，坏历史拒绝，不借当前同名绑定 |
| 卡片只读和分页 | 仅目标正文与必要依赖，来源变化使游标过期，查询不改字节/mtime，未检查不写成功 |
| 旧卡片 Demo 基线 | 真正文件/文档/绑定/框架变化在任何工作稿/任务/检查点写入前拒绝，保留用户输入 |
| 真实内嵌宿主 | 分别观察 PRD 修改、Demo 修改、旧基线拦截与当前对话请求；wrapper/DOM 不能代替，未验证保持消息桥关闭 |
| 呈现失败与降级 | 需求图服务失败返回 unavailable/error，业务保存仍成功；先交付真实回执，再按 snapshotCommand 和文件入口降级，不重放业务写入；无桥复制请求，新聊天读取已登记任务 |
| 临时安装闭包 | 新模板、脚本、schema、重建管理界面齐全；仅显式临时安装，不全局同步 |

使用者可以运行 `python3 -B <skill-dir>/scripts/flow.py validate <project-dir>` 检查项目结构，并按上表验证需要的操作。公开分发包不包含开发测试；维护者仅在开发仓库根运行 `python3 -B -m unittest discover -s tests -v`。技能 frontmatter 可用 skill-creator 的 `quick_validate.py` 检查。结构检查只证明对应结构约束；浏览器实际操作需保留截图或操作证据，云端行为必须注明模拟或真实。

验证新 Skill 的决策时可用隔离项目做独立场景演练：给出原始资料、一个有冲突的既有 PRD 和局部请求，让 Agent 只处理本次范围；观察其是否保留出处、复用已有 Skill、选择正确阶段并遵守真实证据边界。演练不触及真实飞书写入、全局安装或无关项目。
