# Data Visualization Preflight

只在 `data_viz` Mode 读取。它约束图表作为决策工具的内容、视觉和交互质量，不要求额外 Viewport 或生产数据连接。

## Data Contract

- 明确受众、决策目标、数据来源、时间范围、单位、时区、聚合方式和数据新鲜度。
- 真实、示例、占位和假设数据必须可辨识；未知数据不得伪装成真实趋势、预测或客户指标。
- Loading、Empty、Partial、Error、Success/Ready 状态按实际流程取舍，不为了凑状态制造虚假场景。

## Visual Read

- 图表标题说明决策对象，不重复页面标题或只写图表类型。
- 视觉编码与数据类型匹配；比较、趋势、分布、组成和关系不能互相替代。
- 数字、单位、小数位、正负号与时间粒度一致；重点数字和图形之间有明确层级。
- Legend、Axis、Label、Tooltip 不遮挡数据；稀疏数据不填满画布，密集数据不依靠不可读的小字号硬塞。
- 按 `references/quality.md` 分配文本角色。轴刻度、日期、单位、异常时长与处置建议是决策内容；日期若用于解释趋势就不是可随意变淡的页脚。SVG 标注按实际显示尺度检查，不只核对 viewBox 内的 font-size。
- 多图并排导致标注拥挤时，优先给主要图更宽的区域、调整分组或允许纵向阅读；深色背景上的灰色文字也使用明确的支持性文字 Token。
- 状态和系列不只依赖颜色；同时使用标签、线型、形状、位置或直接标注。
- 装饰面积不得超过信息本身的视觉权重；没有决策意义的图形应删除。

## Interaction

- Hover/Focus/Touch 的 Tooltip 信息一致且可离开；重要值不能只存在于 Hover。
- Legend、筛选、时间范围、排序、钻取和恢复操作必须有可观察结果。
- Resize 后容器仍为非零尺寸，Axis/Legend/Tooltip 不重叠，图表不会白屏。
- 异步更新提供 pending 与失败恢复；筛选后保留用户上下文，重置行为明确。
- 可见控件必须可工作、明确 disabled，或标为 Demo 范围外。

## Evidence

- 保留初始/Ready、关键筛选结果，以及适用的 Empty/Error/Recovery 截图。
- 记录数据来源状态、执行的 action、可观察结果和未运行检查。
- 人工检查语义、层级与数据诚实性；机械检查只证明容器、可见性、溢出、状态映射和声明的交互结果。
