# Data Visualization Preflight

`data_viz` Mode 按[数据可视化](page-design/data-viz.md)决定数据口径、图形、标注、适用状态和交互。文字角色与实际 CSS 尺度参见 `references/quality.md`。

在 Demo 的目标视口确认容器可见且尺寸非零，检查 Resize 后的 Axis、Legend、Tooltip 与 SVG 标注实际显示尺度。对声明的筛选、切换、钻取或恢复执行相应操作，记录数据来源状态和可见结果。保留 Ready、关键筛选以及适用的 Empty、Error 或 Recovery 截图。范围内控件须可工作、明确 disabled 或交代 Demo 范围。证据来自本次实际渲染与操作，未测项目如实记录。
