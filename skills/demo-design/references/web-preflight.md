# Web 高保真 Demo 预检

适用于 Web Route 的最终页面。Tier 1/2 检查变更位置和直接受影响的状态与视口，Tier 3 检查主要任务及完整交付。按[Web 页面](page-design/web.md)核对本页实际涉及的布局、文字、控件、素材和响应方式。

## 在最终入口检查

- 在约定的桌面视口看页面本体，确认标题、必要说明和主要操作可见。桌面主 CTA 的标签清楚且能放在一行；营销 Hero 的长标题若接近四行，先检查文案与可用宽度。
- 表单实际输入、Placeholder、焦点、禁用、提交中与错误反馈按实现检查。按[文字与颜色](page-design/web.md#文字与颜色)从真实 CSS 和截图核对前景与背景、支持文字和必要单位。
- 检查图片区、列表、表格、卡片和图文顺序是否对应真实内容，重复项能否按相同字段扫读。拼图网格空格、套叠的圆角容器、无语义的彩色侧线或素材标签，按[视觉与文案](page-design/visual.md)判断其用途。
- 按约定的输入方式验证主要操作、焦点与悬停反馈。使用滚动、固定或持续动效时检查减少动态效果设置。Emoji 遵从 Demo 入口约定，素材随目录可用。
- 只有交付范围包括移动视口或断点时，才追加对应检查。对无更具体要求的移动 Web Demo，可按窄于 768 CSS px 的多列变化、正文 16 CSS px、触控目标 44 × 44 CSS px 复核；全高容器看实际可视区和滚动，避免操作被挤出。
- 按 `references/verification.md` 记录观察到的截图与交互结果。Tier 3 对阻塞或重要问题集中修正并复验相关路径；完整回归、Console 捕获或像素 Diff 按约定档位执行。
