# 数据可视化

先弄清读者要用图表做什么决定，以及数据来源、时间范围、单位、时区、粒度、聚合方式和更新状态。真实数据、示例、缺失和暂时不可用分别表达。对照目标选择视觉编码，例如比较不同对象、读连续趋势、看组成或发现分布差异。

标题说明读者在看什么。数字、正负号、小数位、单位与时间粒度一致。轴、图例、直接标注和关键异常承载决策信息，给足字号、宽度和对比。密集图表可调整分组、增加主图宽度或允许滚动。多系列结合标签、位置、形状或线型表达差异。

筛选、缩放、图例切换和钻取按已有业务决定；悬停、聚焦和触摸能取得相应数据，Tooltip 可离开，图例不遮挡主要数据。观察实际图形的可见区域、标注避让与更新反馈，尤其是范围变化、无结果和查询失败的状态。静态画板可以核对图形层级、数字口径和状态差异；运行中的图表再检验数据更新与交互。
