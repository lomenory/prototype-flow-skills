# 飞书 CLI 能力地图

本参考来自《飞书 CLI 能力介绍与最佳实践》文档快照（更新日志包含至 V1.0.74）。它用于选择业务域和设计工作流，不作为稳定命令语法；执行前始终用本机 `help`、`<command> --help` 和 `schema` 校验。

## 认证与身份

| 目标 | 基础命令或处理方式 |
|---|---|
| 初始化应用配置 | `lark-cli config init` |
| 用户身份登录 | `lark-cli auth login` |
| 查看登录状态 | `lark-cli auth status` |
| 检查已有权限 | `lark-cli auth check` |
| 申请业务域权限 | `lark-cli auth login --domain <domain>` |
| 申请报错指定的 scope | `lark-cli auth login --scope "<missing_scope>"` |
| 查看实际执行身份 | `lark-cli whoami` |
| 登出 | `lark-cli auth logout` |
| 更新 CLI | `lark-cli update` |

用户身份适合访问个人消息、日历、文档和以本人名义执行操作。应用身份适合 Bot 或企业 Agent，但还需遵守企业管控，并在飞书开放平台配置对应权限。

## 常见跨域工作流

### 从会议内容执行待办

1. 读取指定妙记的摘要、待办、章节或逐字稿。
2. 把“信息整理”和“对外动作”分开列出。
3. 解析文档、收件人、日程参与人和时间。
4. 对用户未明确授权的外发或高影响动作先展示计划。
5. 分别发送消息、共享文档、创建任务或安排会议。
6. 逐项读回状态，报告未执行或失败项目。

示例请求：`读一下这个妙记，把待办提取出来并帮我执行；执行前先给我看计划。`

### 文档共创与审稿

- 写作模式：收集上下文 → 创建云文档 → 返回链接 → 读取评论 → 定点修改 → 评论标识修改点。
- 审稿模式：读取全文 → 找到具体文本范围 → 只添加划词评论，不直接改正文。
- Markdown 转文档：保留标题、列表、表格、代码块、高亮块和图片；创建后读回结构抽查。

示例请求：`根据这篇文档上的评论修改正文，修改后用划词评论标出改动。`

### 跨时区多人约会

1. 解析群成员并过滤机器人或无关成员。
2. 获取参与人的忙闲和时区。
3. 在合理工作时间内推荐多个共同空档。
4. 用户选择后创建日程并按需预订会议室。
5. 核对邀请人、时区、会议链接和会议室状态。

### 会议审计与多维表格仪表盘

1. 分页拉取指定时间范围的日程或妙记。
2. 建立分类标准和评分口径。
3. 创建或解析多维表格字段。
4. 批量写入并核对总记录数。
5. 创建视图、图表或仪表盘并返回链接。

### 未读邮件分类

1. 搜索所有符合范围的未读邮件并处理分页。
2. 按用户认可的规则分类和摘要。
3. 对重要邮件创建草稿回复。
4. 仅在用户授权后发送、归档、改标签或移入废纸篓。
5. 报告每类数量和处理结果。

## 易错点

- 安装后命令不存在：确认 npm 全局可执行目录在 `PATH`，可用 `npm root -g` 定位。
- OAuth 授权码过期：重新执行 `lark-cli auth login`。
- 权限不足：按错误中给出的 domain 或 scope 最小化补权；应用身份还要检查开放平台后台。
- 身份不符：用 `lark-cli whoami` 确认实际身份，不要把应用发送误报为本人发送。
- 结果不全：处理分页、截断提示和时间范围，不只读取第一页。
- 重复日程误改：明确“仅本次”“全部”或“从本次往后”。
- 文档/表格误覆盖：写入前确认选区、区域、追加/替换和版本恢复路径。
- 异步任务误报完成：查询恢复、导入、导出或发布进度，区分已提交与已完成。
- 配置完成但 Agent 看不到新 skills：重启当前 Agent 工具。
- Codex 沙箱阻止命令：申请当前操作所需的最小权限，不要全面关闭安全限制。
